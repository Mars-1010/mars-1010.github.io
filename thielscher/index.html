01 / Selected project

Game Fellows

I built a game companion that moves in formation, intercepts incoming shots and coordinates support fire. The reproducible build reads the game state and follows explicit rules. In a separate prototype, I explored using successive screenshots to inform actions and spoken feedback.

I also set up solo and companion conditions using matched random seeds and added event logging so I could compare what happened during play.

02 / Research interests

What does the agent know?

When an AI companion has only part of the picture, how should it decide whether to act, wait, or ask?

In Game Fellows, access to the game state makes decisions straightforward. With screenshots alone, a companion may miss a threat or lose track of the player. I want to represent what it observed, what it inferred, and what must be true before a proposed action is appropriate.

I would start by comparing a screenshot-based companion with one that also checks explicit action rules. Using matched scenarios with missing or conflicting observations, I would measure invalid actions, missed opportunities to help, and how often the companion interrupts the player. My longer-term goal is to bring that reasoning into personal AI that can revise its understanding when a user corrects it or a shared task changes.

A starting point: Schiffel and Thielscher’s work on general games with imperfect information, which separates game rules from what a player can observe.
