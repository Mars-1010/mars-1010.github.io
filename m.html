02 / RESEARCHDOCTORAL RESEARCH PROPOSAL

Knowing when
help is welcome.

When would someone welcome a specific hint or editing proposal?

My proposed research uses visual editing to study when AI should wait, offer a hint, or preview an edit requiring confirmation. Participants would create event posters and practise an unfamiliar alignment operation, so the same suggestion can be considered under different work goals.

Using the same task records and feedback, I will compare explicit task-relevance and receptivity estimates with direct and value–cost models. The studies would evaluate welcome predictions and practical effects, then examine how feedback should be reconsidered as goals change.

Boundaries is a related early browser prototype exploring previews and user control. It does not implement the proposal’s welcome predictor; participant evaluation and headset testing have not been conducted.
